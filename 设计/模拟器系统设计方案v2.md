# 命运模拟器系统设计方案 v2.0

> 核心原则：模拟器的爽点 = **信息差优势**。玩家通过模拟预知未来，在现实中获得别人没有的信息，从而做出更优决策。

## 一、核心循环

```
现实剧情 → 遇到抉择点 → 花费灵石启动模拟 → 从当前节点推演未来
    ↑                                              ↓
    ← 利用预知信息做更优选择 ← 选择奖励带回现实 ← 模拟结束（死亡/寿终）
```

### 爽点拆解

| 阶段 | 玩家体验 | 小说对应 |
|------|---------|---------|
| **预知** | 在模拟中看到未来的危险/机遇 | 《苟在修仙》看到被劫杀 |
| **布局** | 回到现实，利用信息提前准备 | 提前躲避陷阱、结交盟友 |
| **验证** | 现实中的选项因预知而改变 | 出现「利用模拟记忆」的特殊选项 |
| **收获** | 因为预知获得了额外好处 | 信息差碾压带来的爽感 |

## 二、模拟流程

### 2.1 启动条件

| 条件 | 说明 |
|------|------|
| 模拟器已解锁 | 剧情到达 ch2_1 时自动解锁 |
| 灵石足够 | 消耗随境界递增（见下表） |
| 有剩余次数 | 每日次数有限（见下表） |
| 不在模拟中 | 同一时间只能进行一次模拟 |

### 2.2 消耗表（随境界递增）

| 境界 | 单次消耗灵石 | 每日上限次数 | 设计逻辑 |
|------|------------|------------|---------|
| 炼气1-3层 | 10 | 3 | 入门期，攒一月约5-6次 |
| 炼气4-6层 | 30 | 5 | 中期，需要更多积累 |
| 炼气7-9层 | 80 | 8 | 后期，每次都是大投资 |
| 筑基+ | 200 | 10 | 未来扩展 |

### 2.3 模拟内容生成

模拟器从当前 storyGraph 节点出发，向未来推演：

1. **场景推进**：复用 storyGraph 的场景树，但选择路径是随机的（模拟平行世界）
2. **随机事件**：除了 storyGraph 中的场景，还会插入「模拟专属事件」
3. **死亡机制**：
   - 战斗/冒险场景有概率死亡（概率与修为、属性相关）
   - 每过一年，「天机反噬」概率递增（越远未来越不确定）
   - 死亡后结算，不会无限拖下去
4. **信息发现**：模拟中会揭示一些「隐藏信息」，如：
   - 敌人的真实意图（柳飞要暗算你）
   - 隐藏地点的位置（后山有灵泉）
   - 未来事件的预警（三个月后有大比）
   - NPC 的好恶（苏长老想收你为徒但有目的）

### 2.4 模拟中的信息收集

模拟结束时，除了传统的奖励（修为/词条），还会生成**记忆碎片**：

```
记忆碎片 = 模拟中发现的关键信息条目

示例：
- 「柳飞的暗器习惯：先风刃远程，再近身绞杀」
- 「后山洞府中有功法口诀和灵石」
- 「苏长老收徒是为了培养炉鼎」
- 「乱风峡谷的风蝮蛇七寸是弱点」
```

这些记忆碎片会被记录到 player.memoryFragments 中。

## 三、预知系统（核心创新）

### 3.1 记忆碎片 → 现实选项

当现实剧情到达关键节点时，如果玩家持有相关的记忆碎片，会解锁**预知选项**：

```
正常选项：
A. 接受柳飞的好意
B. 礼貌拒绝

如果有记忆碎片「柳飞的暗器习惯」：
C. 🔮 提前防备他的暗器（需要记忆碎片：柳飞的暗器习惯）
```

```
正常选项：
A. 继续往前探索
B. 绕路走安全的路

如果有记忆碎片「后山洞府位置」：
C. 🔮 去那个隐蔽的洞府看看（需要记忆碎片：后山洞府位置）
```

### 3.2 预知选项的效果

- **不是必胜选项**，而是**信息优势选项**
- 通常消耗记忆碎片（用完即消失）
- 可能带来更好的结果（避开陷阱、获得额外资源）
- 但也可能有风险（改变了命运轨迹，可能触发新的未知事件）

### 3.3 记忆碎片的生命周期

```
模拟中发现 → 结算时选择保留 → 记录到 player.memoryFragments
    → 现实剧情中匹配到使用场景 → 解锁预知选项
    → 玩家选择使用 → 消耗碎片，获得优势
    → 或者一直不用（留着备用，但占位置）
```

## 四、结算系统

### 4.1 模拟结束条件

| 条件 | 说明 |
|------|------|
| 角色死亡 | 战斗中陨落、被暗杀等 |
| 寿元耗尽 | 模拟中活到寿命上限 |
| 天机反噬 | 推演过远，命运轨迹崩溃 |
| 到达故事终点 | 推演到了当前章节的结局 |

### 4.2 结算奖励

模拟结束后，根据表现给出评价（S/A/B/C/D），然后提供奖励选项：

| 评价 | 条件 | 奖励品质 |
|------|------|---------|
| S | 存活久+突破境界+发现3+信息 | 高品质词条 + 2个记忆碎片 |
| A | 存活久+突破境界 | 中品质词条 + 1个记忆碎片 |
| B | 存活较久 | 修为灌注 + 1个记忆碎片 |
| C | 存活一般 | 修为灌注 |
| D | 很快死亡（<10年） | 微量修为 |

### 4.3 奖励类型

1. **修为灌注**：将模拟中的修炼感悟融入现实（直接加修为）
2. **记忆碎片**：模拟中发现的关键信息（用于解锁预知选项）
3. **词条铭刻**：模拟中的天赋固化为永久能力（白色/绿色/蓝色品质）
4. **天机点**（可选）：特殊货币，用于刷新/升级奖励

## 五、模拟中的叙事风格

### 5.1 模拟文本 vs 现实文本

- **现实文本**：详细的场景描写，NPC对话，沉浸式体验
- **模拟文本**：更简洁的「命运投影」风格，像是模糊的预知画面

```
模拟文本风格示例：

「命运投影开始——」

「你看到自己走进了后山的密林。在一处岩缝前，你犹豫了片刻，最终侧身挤入。」
「通道尽头是一座洞府。石壁上有功法，角落有灵石。」
「你选择了修炼功法。灵气涌入体内，修为暴涨——」
「但就在这时，一道黑影从背后袭来……」

「命运投影结束。存活：3年。发现信息碎片×1。」
```

### 5.2 模拟中的选择

模拟中的选项更简洁（模拟节奏更快）：
- 每个场景只显示 2 个选项（而非 3-4 个）
- 选择后快速推进（1-3 年/次）
- 文字更概括，不展开细节

## 六、技术实现要点

### 6.1 记忆碎片匹配机制

```javascript
// 记忆碎片的数据结构
{
  id: 'insight_liufei_pattern',
  name: '柳飞的暗器习惯',
  description: '先风刃远程，再近身绞杀',
  // 这个碎片在哪些场景可以使用
  usableAtScenes: ['ch2_4', 'ch3_5', 'ch4_2'],
  // 使用后解锁的预知选项
  unlocksChoice: {
    id: 'C_preview',
    text: '🔮 提前防备他的暗器',
    effect: { avoidDamage: true, bonusCultivation: 200 }
  }
}
```

### 6.2 每日次数重置

```javascript
// player.flags 中记录
sim_daily: {
  date: '2026-08-18',  // 上次模拟日期
  count: 2,             // 今日已用次数
}
```

### 6.3 天机反噬概率

```javascript
// 模拟中每年递增的死亡概率
function getDeathProbability(yearsElapsed, realmLevel) {
  const baseChance = 0.02; // 基础2%/年
  const realmFactor = 1 + realmLevel * 0.1; // 高境界活得久一点
  const timeFactor = 1 + (yearsElapsed / 20); // 时间越长越危险
  return Math.min(0.3, baseChance * realmFactor * timeFactor);
}
```
