## 一、师傅型NPC

### 1. 赵无涯

| 项目 | 内容 |
|------|------|
| **身份** | 青云宗外门执事长老 |
| **境界** | 筑基后期（巅峰多年未寸进） |
| **年龄** | 外表四十余岁，实际一百二十岁 |

**外貌描写**：  
方脸阔额，颧骨高耸，一双眼睛如鹰隼般锐利。常年着一件洗得发白的青色执事袍，腰间挂一枚铜制令牌。左手少了两根手指，据说是年轻时执行宗门任务所致。

**性格特点**：**严厉、公正、寡言**  
赵无涯从不说废话，每句话都是命令或判断。弟子们私下叫他"铁面赵"，恨他的人不少，但没人敢说他不公。

**背景故事**：  
赵无涯出身青云宗外门，资质平平，靠着一部黄阶中品的《磐石功》苦修三十年才筑基成功。他深知底层弟子的艰难，却从不明示善意——在他看来，"宗门不养闲人，修仙界更不养"。他曾向掌门进言改革外门制度，给底层弟子更多修炼资源，却被驳回。此后他再未多言，只是默默在自己的权限范围内，为外门弟子争取微薄的福利。他知道宗门在走下坡路，却选择维护这个注定衰败的体制——因为他没有更好的选择。

**与主角关系**：  
- **初始**：冷淡的上司与下属。入门时只说了一句"修炼去吧"。
- **发展中**：逐渐发现主角的韧性，开始暗中给予指导，但始终冷面。后期会传授主角一部功法。

**独特口癖/说话风格**：  
- 说话从不超过三句，每句都是短句。
- 示例1：（主角入门时）"四灵根。不算好。但也不算最差。去外门丙字院报到。"
- 示例2：（主角修炼出问题时）"经脉有灼热感？那是灵气淤积。停三日再修。别问我为什么——你自己试过了就明白了。"
- 示例3：（大比前）"活着回来就行。"

**NPC秘密**：  
1. **断指之秘**：赵无涯的左手断指并非宗门任务所致，而是年轻时误入一处古修遗迹，触碰了一卷禁忌玉简后被反噬。那卷玉简的内容他至今记得——是一部残缺的天阶功法。他将这个秘密埋藏了百年。
2. **改革之心**：赵无涯暗中保存了一份外门制度改革方案，等待一个"值得投资"的弟子出现时，将方案交给他——让弟子去推动改革，自己已无力为之。

**关键剧情作用**：  
- 第一章引入主角进入外门，是主角与宗门体制的第一次接触
- 第二章中在主角修炼遇到瓶颈时给予点拨（但以严厉方式）
- 第四章大比中作为裁判之一，暗中观察主角表现
- 第五章中若主角表现优异，传授功法并暗示改革方案

### 2. 李玄真（老李头）

| 项目 | 内容 |
|------|------|
| **身份** | 丹房杂役，名义上负责打理丹房药材 |
| **境界** | 表面：凡人（无灵根波动）；实际：筑基初期（修为被封印/废去大半） |
| **年龄** | 外表六十余岁，实际九十多岁 |

**外貌描写**：  
佝偻着背，满头花白乱发，一张老脸上布满皱纹和灼伤疤痕。总是穿着油腻的粗布衣裳，身上带着一股草药和焦糊混杂的气味。右眼微眯，左眼却时常透出与年龄不符的精光。

**性格特点**：**慵懒、通透、藏拙**  
老李头整天缩在丹房角落打盹，说话只说半截，让人自己去悟。看似是个混吃等死的杂役，实际上对丹道和修炼的理解远超普通筑基修士。

**背景故事**：  
李玄真三十年前是苍梧大陆小有名气的金丹期炼丹师，一手"玄火炼丹术"令无数修士趋之若鹜。然而在替一位大势力家主炼制突破丹药时，丹炉爆炸，不仅修为尽废，还搭上了三条人命。此事之后，他被炼丹师公会除名，走投无路之下投入青云宗做了杂役。他一直在暗中寻找修复经脉的灵药"九转续脉丹"的最后一味——而这种灵药，据说藏在青云山脉深处。

**与主角关系**：  
- **初始**：主角被分配帮丹房搬运药材时相识。老李头对主角态度随意，偶尔指点一二。
- **发展中**：主角若在模拟中获取丹道相关记忆碎片，可引起老李头注意，逐渐成为忘年交。后期会传授主角基础丹道知识。

**独特口癖/说话风格**：  
- 说话总说半截，然后就不说了，让你自己悟。
- 示例1："这聚气丹嘛……嗯，你看看丹纹，数数几道。算了，你自己数。"
- 示例2："灵气运行到膻中穴的时候……嘶……这个，你回去再练练。我说了你也不信，得自己试过。"
- 示例3：（主角问及高阶丹道时）"金丹期炼丹？嘿嘿……老头子我见过最好的丹炉炸了，最好的丹师废了，最好的丹药……吃了还不如不吃。"

**NPC秘密**：  
1. **真实身份**：前金丹期炼丹师，被炼丹师公会除名。青云宗上下无人知晓其真实来历。
2. **丹炉爆炸真相**：三十年前的事故并非意外——是有人在他的丹方中动了手脚，目的是掩盖一次以炼丹为幌子的毒杀阴谋。老李头隐约猜到幕后之人，但苦无证据。

**关键剧情作用**：  
- 第三章坊市之行中，主角为他寻找一味药材，加深关系
- 传授主角基础丹道知识，解锁炼丹玩法前置
- 第五章中若关系达到"信任"，透露自己的真实身份和仇人线索（正式版伏笔）

## 二、师姐/师兄型NPC

### 3. 苏清寒

| 项目 | 内容 |
|------|------|
| **身份** | 青云宗内门弟子，赵无涯记名弟子 |
| **境界** | 炼气九层（巅峰） |
| **年龄** | 外表二十二三岁，实际四十五岁 |

**外貌描写**：  
眉目清冷如霜，肤白胜雪，一头青丝以一根素色发带束起。常着白色内门弟子服，腰间悬一柄细长的青色法剑。走路时目不斜视，周身似有一层无形的寒意。

**性格特点**：**清冷、疏离、孤独**  
苏清寒从不用正眼看人，说话总带一个"呵"字，仿佛一切都不值得她认真对待。但熟悉她的人知道，这份冷漠之下是一颗渴望真正友情却不知如何表达的心。

**背景故事**：  
苏清寒是青云宗苏长老的侄女，天赋出众（双灵根），却被宗门上下视为"长老安插在弟子中的眼线"。她实际上极度厌恶这种身份——她不想当谁的棋子，却无力反抗叔父的安排。每次她试图和外门弟子平等相处，都会被对方敬畏或讨好的态度推开。久而久之，她选择了冷漠作为铠甲。赵无涯是她唯一尊敬的人，因为赵长老从不对她特殊对待。

**与主角关系**：  
- **初始**：冷淡。偶尔在外门巡视时遇到主角，态度高高在上。
- **发展中**：主角若在模拟中发现她的秘密（被安排监视外门弟子），可以选择当面揭穿或暗中帮她解脱，走向截然不同的关系路线。

**独特口癖/说话风格**：  
- 从不用正眼看人，说话末尾习惯带一个"呵"。
- 示例1："外门弟子的修炼进度？……呵，赵长老让我来问的，不是我想知道。"
- 示例2：（主角表现超出预期时）"不错。……呵，我只是陈述事实，不是在夸你。"
- 示例3：（关系深入后，罕见地流露真情）"你……不用在意别人怎么看我。我习惯了。……呵，别用那种眼神看我。"

**NPC秘密**：  
1. **眼线身份**：奉叔父苏长老之命，暗中监视外门弟子的修炼情况和人际往来，定期汇报。她厌恶这项工作却无法拒绝。
2. **修为瓶颈真相**：她的炼气九层巅峰已维持三年，迟迟无法筑基。原因不是天赋不够，而是她暗中修炼了一部来历不明的功法——这部功法修炼速度极快，但有一个代价：每突破一个小境界，就会失去一段重要的情感记忆。

**关键剧情作用**：  
- 第二章首次出场，给主角施加压力（"你就是那个四灵根的新人？呵。"）
- 第三章中若主角帮助她摆脱眼线身份，可成为强力盟友
- 第四章大比中态度转变，成为主角的暗中支持者
- 第五章引出新剧情线（苏长老的阴谋）

### 4. 林若烟

| 项目 | 内容 |
|------|------|
| **身份** | 青云宗内门首席弟子，宗主亲传 |
| **境界** | 炼气九层（巅峰），即将冲击筑基 |
| **年龄** | 外表二十五岁，实际五十岁 |

**外貌描写**：  
容貌秀美，气质温和，一双桃花眼笑起来弯如月牙。常着绣有金色云纹的内门弟子服，发间别一枚翠绿色的灵玉簪。说话时声音轻柔，令人如沐春风。

**性格特点**：**温婉、聪慧、隐忍**  
林若烟是青云宗公认的天才弟子，待人温和有礼，从不摆首席架子。但她温和的表面下藏着极深的城府——她知道自己迟早要接过宗主的重担，所以每一步都在计算。

**背景故事**：  
林若烟出身青云山脉一个小家族，幼年时全家遭遇妖兽袭击，唯有她被路过的青云宗宗主救下。宗主见她天赋卓绝（天灵根·木），收为亲传弟子。她对宗主感恩戴德，但也逐渐发现宗主的"仁慈"不过是另一种利用——宗主培养她，是为了让她将来与某大势力的继承人联姻，以换取宗门庇护。她表面顺从，暗中却在积蓄力量，等待有一天能摆脱这层棋子的命运。

**与主角关系**：  
- **初始**：友善但保持距离。大比中作为内门观众出场。
- **发展中**：若主角展现出非凡潜力，会主动示好，但她的善意总有深意。

**独特口癖/说话风格**：  
- 说话温柔但滴水不漏，从不正面拒绝人，却让人摸不透真实想法。
- 示例1："师弟加油呢。大比的结果……其实没那么重要。重要的是，你让所有人看到了你。"
- 示例2：（对主角的选择表示赞赏时）"你比我想象中聪明。……别紧张，这是夸奖。"

**NPC秘密**：  
1. **联姻之局**：宗主与某大宗门达成的联姻协议，她知情但无力反抗。
2. **暗中布局**：她在内门中培养了自己的小圈子，暗中收集宗门各派系的情报。

**关键剧情作用**：  
- 第四章大比出场，作为"天花板"让主角仰望
- 第五章正式互动增多，引出正式版"内门篇"主线

## 三、竞争对手型NPC

### 5. 王虎

| 项目 | 内容 |
|------|------|
| **身份** | 外门首席弟子 |
| **境界** | 炼气七层 |
| **年龄** | 外表二十六岁，实际四十岁 |

**外貌描写**：  
身材魁梧如铁塔，浓眉大眼，面庞粗犷。双臂肌肉虬结，手背布满老茧。穿外门弟子服时总把袖子挽到肘部，腰间别一把宽背大刀。永远昂着下巴看人。

**性格特点**：**傲慢、霸道、重情**  
王虎在外门横行霸道，抢任务、占资源、欺负新人，外门弟子敢怒不敢言。口头禅是"你也配？"。但了解他的人知道，他做这一切都是为了一个人——他年幼的弟弟王小龙。

**背景故事**：  
王虎的弟弟王小龙先天身患灵毒，需要定期服用"清灵丹"压制毒素，而这种丹药每月需要三枚，每枚价值五枚下品灵石。王虎出身寒门，父母早亡，兄弟二人相依为命。为了赚取弟弟的药费，王虎不得不拼了命地抢任务、争资源。他的霸道不是为了自己，而是为了让弟弟活下去。他知道自己在做不对的事，但在"弟弟的命"和"道德"之间，他永远选前者。

**与主角关系**：  
- **初始**：敌对。王虎视所有威胁外门资源分配的人为敌人。
- **发展中**：大比中若主角击败他，他会记恨但不会报复（因为主角证明了自己的实力）；若主角帮助他的弟弟，关系可彻底翻转。

**独特口癖/说话风格**：  
- 永远昂着下巴看人，口头禅"你也配？"
- 示例1：（主角去领任务时）"丙字院的新人？这里的甲乙级任务，你也配接？"
- 示例2：（大比中被击败后）"……你赢了。但你别得意，下一次，我不会再手下留情。"
- 示例3：（主角帮助他弟弟后，态度巨变）"你……你这个人。行了，以后有什么事，报我王虎的名字。"

**NPC秘密**：  
1. **弟弟灵毒真相**：王小龙的灵毒并非天生，而是幼年时误食了有人故意投放在村中的毒物。投毒之人是为了测试一种新型灵毒的效果——而这个实验与苏长老暗中进行的某项研究有关。
2. **隐藏实力**：王虎实际已触及炼气八层门槛，但刻意压制修为。因为一旦突破八层，就必须参加内门选拔，届时弟弟将失去外门弟子家属的丹药配给资格。

**关键剧情作用**：  
- 第一、二章中作为前期对手，给主角施压
- 第四章大比中的关键对手——击败他是"逆袭"的核心爽点
- 第五章中若关系翻转，成为主角在外门的坚实后盾

## 四、朋友型NPC

### 6. 陈墨

| 项目 | 内容 |
|------|------|
| **身份** | 外门丙字院弟子，与主角同期入门 |
| **境界** | 炼气三层（中期） |
| **年龄** | 外表十七岁，实际十九岁 |

**外貌描写**：  
中等身材，面容老实憨厚，一双眼睛不大但很亮。总是微微驼着背，走路时低着头，像是怕被人注意到。手指上有厚厚的茧——不是因为练功，而是因为从小在家干农活。

**性格特点**：**忠厚、怯懦、深藏**  
陈墨是主角入门后第一个交到的朋友。他老实、话少、容易紧张，每次被人欺负都忍气吞声。但在危急时刻，他反而会爆发出惊人的冷静和果断。他有一个谁都不知道的秘密——他在暗中修炼一部被宗门禁掉的功法。

**背景故事**：  
陈墨出身凡人农家，家中兄弟五人，他排行老三。被青云宗收为弟子的那天，全家欢天喜地，以为出了个"仙人"。但入门后他才明白，四灵根的自己在宗门里连杂役都不如。一次偶然的机会，他在整理藏书阁废旧玉简时发现了一卷残破的竹简——上面记载着一部名为《噬灵诀》的功法。这部功法可以吞噬他人残余的灵气为己用，被正道宗门列为禁术。陈墨知道这是禁忌，但他更知道，以他的资质，正常修炼这辈子都别想筑基。他开始偷偷修炼，每次都在深夜无人的后山。

**与主角关系**：  
- **初始**：好友。同期入门，同病相怜，互相照应。
- **发展中**：若主角发现他的秘密，选择揭发还是守密将决定关系走向——守密则成为生死之交，揭发则反目成仇。

**独特口癖/说话风格**：  
- 平时紧张就结巴，但危急时刻反而口齿伶俐。
- 示例1：（平时）"那个……师、师兄说今天有任务，咱、咱们要不要去？"
- 示例2：（遇到危险时，突然不结巴了）"别慌！左侧有灵气波动，三个人，两个炼气初期，一个……至少四层。从右边绕，快！"
- 示例3：（被主角撞见修炼禁术时）"你……你都看到了？我……你听我说，我不是什么坏人，我只是……我只是不想一辈子被人踩在脚下。"

**NPC秘密**：  
1. **禁术修炼者**：暗中修炼《噬灵诀》，这门功法可以吞噬他人残余灵气，被正道宗门严禁。一旦暴露，将被逐出宗门甚至处死。
2. **真实悟性**：陈墨的真实悟性远高于表面——他之所以能发现并理解《噬灵诀》这种复杂禁术，是因为他拥有罕见的"暗悟"体质：在极端压力下，思维速度会暴增数倍。这也是他危急时刻不结巴的原因。

**关键剧情作用**：  
- 第一至三章中作为主角最亲密的伙伴，提供情感支撑
- 第三章历练中遭遇危机，他的秘密可能暴露
- 第四章大比中若主角守住了他的秘密，他会拼死相助
- 第五章引出正式版"禁术"支线

### 7. 周德厚（周胖子）

| 项目 | 内容 |
|------|------|
| **身份** | 青云城散修商人，经营一间小铺"厚道杂货铺" |
| **境界** | 炼气六层 |
| **年龄** | 外表三十五岁，实际六十八岁 |

**外貌描写**：  
圆脸圆肚，笑眯眯的眼睛几乎眯成一条缝。穿着一件半新不旧的灰色道袍，手指上戴了四五个储物戒指——据他自己说是"进货方便"。

**性格特点**：**圆滑、热心、精明**  
周胖子嘴上永远挂着"公道价、童叟无欺"，实际上精明得跟鬼一样。但他有个底线——不卖假货，不坑穷人。对穷困潦倒的低阶修士，他偶尔会"忘了"收钱。

**背景故事**：  
周德厚年轻时也是个有抱负的修士，可惜资质平庸，修炼无望后转行做了商人。他在修仙界底层摸爬滚打几十年，消息灵通，人脉广泛。他的杂货铺虽小，却是青云城情报集散地之一。他最大的遗憾是没能进入一个大宗门，所以他特别照顾青云宗的低阶弟子——价格公道，偶尔还免费指点修炼。

**与主角关系**：  
- **初始**：普通商客关系。主角去坊市时认识。
- **发展中**：若主角经常光顾并且讲信用，会成为可靠的信息来源和交易伙伴。

**独特口癖/说话风格**：  
- 说话总是笑嘻嘻，喜欢用"公道"两个字。
- 示例1："哎哟，小道友来啦！看看看看，新到的一批灵草，绝对公道价！"
- 示例2：（透露消息时）"这个消息嘛……本来不该我说。但谁让咱们是老相识呢？不过嘛，这'老相识'的情分，也是有价钱的……"
- 示例3：（关心主角时）"小道友，修炼别太拼命。活着才能修仙，死了就什么都没了。这话不好听，但公道。"

**NPC秘密**：  
1. **情报网络**：周胖子表面上是个小商人，实际上暗中维护着一个覆盖南疆边陲的情报网络，消息来源极为广泛。
2. **隐藏身份**：他是某个已覆灭的中型宗门的遗孤，对青云宗的兴衰有着特殊的关注——他在等一个机会，等一个能改变南疆修仙界格局的变数。

**关键剧情作用**：  
- 第三章坊市之行中出场，为主角提供关键信息和物资
- 提供修仙界动态和势力情报，拓展世界观
- 第五章正式引入"南疆修仙界"更大的格局

## 五、反派型NPC

### 8. 柳飞

| 项目 | 内容 |
|------|------|
| **身份** | 外门乙字院弟子 |
| **境界** | 炼气六层 |
| **年龄** | 外表二十三岁，实际三十八岁 |

**外貌描写**：  
面容白净俊朗，嘴角常挂着温和的微笑，看起来像个谦谦君子。手指修长白皙，动作优雅从容。但仔细看他的眼睛，笑意从未到达眼底。

**性格特点**：**阴狠、隐忍、极端**  
柳飞笑着杀人，动手前总说"得罪了"。他是外门中最危险的弟子——不是因为修为最高，而是因为他最擅长在对手最放松的瞬间给予致命一击。

**背景故事**：  
柳飞出身寒门散修家庭，幼年时父母被一个世家子弟为争夺灵矿而杀害。他被青云宗收留后，拼命修炼，却发现这个世界的规则从未改变——世家子弟生来就有最好的功法、最多的资源、最硬的靠山，而他这样的小人物，再怎么努力也爬不过去。于是他决定不择手段。他表面温文尔雅，暗中钻研各种阴险手段——暗器、毒术、心理战。他的目标不是简单地赢得大比，而是要让所有看不起他的人知道：规则，是可以被打破的。

**与主角关系**：  
- **初始**：表面友善，实际将主角视为潜在威胁。
- **发展中**：大比中是主角最危险的对手。若主角在模拟中获得关于他的记忆碎片，可以提前识破他的暗算。

**独特口癖/说话风格**：  
- 笑着说话，动手前总说"得罪了"。
- 示例1：（初次见面，微笑拱手）"在下柳飞，久仰道友大名。同为外门弟子，日后还请多多关照。"
- 示例2：（大比中暗算对手时，轻声说）"得罪了。放心，不会太疼的。"
- 示例3：（被主角揭穿后，笑容消失，眼神冰冷）"你以为你是正义的一方？你不过是运气好，投了个好胎罢了。我走的每一步，都是被逼的。"

**NPC秘密**：  
1. **复仇计划**：柳飞暗中联络了几个同样被世家欺压的外门弟子，策划在大比期间制造混乱，趁机窃取宗门宝库中的灵药——他要用这些灵药提升实力，去找当年杀害父母的仇人复仇。
2. **真正的实力**：柳飞对外展示的是炼气六层，实际上已突破到炼气八层。他一直隐藏实力，就是为了在大比中给所有人一个"惊喜"。

**关键剧情作用**：  
- 第二至三章中作为暗线反派，表面友善实则暗中布局
- 第四章大比中的终极对手——模拟中的死亡就是被他暗算
- 玩家的核心选择：击败他之后，是揭穿他还是放他一马？这个选择影响正式版剧情走向

## 六、神秘人型NPC

### 9. 灰袍老者

| 项目 | 内容 |
|------|------|
| **身份** | 不明。偶尔出现在青云山脉深处的神秘修士 |
| **境界**：不明（深不可测） |
| **年龄**：不明 |

**外貌描写**：  
一身灰色旧袍，兜帽遮住了大半张脸，只露出花白的下巴和一撮长须。身形瘦削，走路时几乎没有声音。左手持一根乌黑的木杖，杖头刻满了看不懂的纹路。

**性格特点**：**莫测、戏谑、引导**  
灰袍老者说话云山雾罩，似乎每一句话都有深意，又似乎只是在胡言乱语。他对主角的态度很微妙——既不帮助也不伤害，只是不断地抛出一些似是而非的暗示。

**背景故事**：  
（玩家不可直接获知，通过碎片逐步揭开）  
灰袍老者实际上是青云宗鼎盛时期第二代祖师的三弟子，一位化神期的老怪物。他在数百年前发现了一个关于青云山脉的惊天秘密——山脉之下封印着一处上古战场遗迹，而宗门建在这里的目的，就是为了守护这个封印。数百年来，他以不同身份在宗门附近游荡，默默守护着封印不被打破——封印与他数百年前立下的道誓息息相关，若封印破碎，他的修行也将付之东流。但近年来封印出现了松动的迹象，他需要一个"变数"来改变局面——而手持命运模拟器的主角，就是他等的那个人。

**与主角关系**：  
- **初始**：主角在第三章历练中偶然遇到。老者说了一句莫名其妙的话后消失。
- **发展中**：在关键节点反复出现，每次都留下一句谶语般的提示。

**独特口癖/说话风格**：  
- 说话云山雾罩，像是打哑谜。
- 示例1：（第一次见面）"有意思……你的命格，老朽看了三百年，头一回见这种。有趣，有趣。"
- 示例2：（大比前出现在主角梦中）"胜者为王？败者为寇？……小娃娃，你可知这盘棋，下棋的人不是你以为的那个？"
- 示例3：（第五章末尾）"风起于青萍之末……南疆的灵气，要变了。小娃娃，好自为之。"

**NPC秘密**：  
1. **真实身份**：青云宗鼎盛时期第二代祖师的三弟子，化神期修士，守护青云山脉封印数百年。
2. **模拟器的关联**：他知道"命运模拟器"的存在——因为它并非凭空出现，而是与青云山脉下的上古遗迹有关。主角获得模拟器，可能不是巧合。

**关键剧情作用**：  
- 第三章初次出场，埋下伏笔
- 第四章大比前给出关键暗示（如果玩家之前选择记住他的话）
- 第五章末尾正式引出"上古封印"这条正式版主线

### 10. 苏长老（苏长卿）

| 项目 | 内容 |
|------|------|
| **身份** | 青云宗内门长老，苏清寒的叔父 |
| **境界** | 金丹初期 |
| **年龄** | 外表五十余岁，实际一百八十岁 |

**外貌描写**：  
面如冠玉，三缕长髯飘逸洒脱，一双凤眼含着似笑非笑的神色。常年着华贵的紫色长老袍，腰间佩一枚上等灵玉。通身气度不凡，一看就是久居高位之人。

**性格特点**：**儒雅、权谋、自私**  
苏长卿在宗门中以"温文尔雅"著称，从不与人正面冲突。但他的每一个"善意"背后都有算计，每一次"退让"都是为了更大的进击。他做一切事情的终极目的只有一个——让苏家在青云宗的地位更加稳固。

**背景故事**：  
苏长卿是青云宗三大内门长老之一，掌管弟子选拔和功法分配。他出身修仙世家苏家，嫁入青云宗后逐步经营自己的势力。他将侄女苏清寒安排为弟子中的眼线，暗中收集各派系情报；他拉拢内门弟子，排挤异己；他甚至暗中与宗门外的势力有交易——用宗门的低阶丹药换取外部势力的支持。他并非大奸大恶之人，在他的逻辑里，"苏家的利益就是宗门的利益"——他只是太习惯于将家族置于一切之上。

**与主角关系**：  
- **初始**：不存在直接关系。主角只是他眼中的一个外门小弟子。
- **发展中**：若主角在大比中表现突出，会引起他的注意——他会试图拉拢主角为己所用。若主角拒绝，则可能成为他的障碍。

**独特口癖/说话风格**：  
- 说话温和有礼，从不提高声音，但每句话都暗含深意和压力。
- 示例1：（对主角微笑）"听清寒提起过你。四灵根，入门不久便炼气三层……不错，年轻人，有前途。"
- 示例2：（拉拢时）"青云宗的未来，终究要靠你们这些年轻人。不过，年轻人的路，有时候需要前辈来引……你说是也不是？"

**NPC秘密**：  
1. **暗中交易**：与宗门外的"天剑门"有秘密交易，用宗门的丹药资源换取对方的支持，目的是在下次掌门选举中获得足够票数。
2. **灵毒实验**：多年前曾在青云山脉外围的凡人村落中秘密测试一种灵毒——目的是开发一种可以控制他人修为的丹药。王虎弟弟的灵毒，正是这场实验的副产品。

**关键剧情作用**：  
- 第四章大比中作为高层出场，暗中观察主角
- 第五章正式与主角产生冲突——引出"苏家阴谋"这条正式版支线
- 与苏清寒、柳飞的秘密都有间接关联，形成叙事网络
