# 《玄衍仙途：命运模拟器》多周目要素（Demo版设计）

> **版本**：v1.0  
> **定位**：正式版核心长线内容，Demo版仅做基础框架预留  
> **说明**：本文档定义跨周目继承规则、周目差异、隐藏内容及终局路线

---

## 一、跨周目继承系统

### 1.1 永久保留内容

| 类别 | 保留内容 | 说明 |
|------|---------|------|
| **成就** | 所有已解锁成就 | 跨周目100%保留，不重置 |
| **称号** | 已获得的称号 | 可在角色面板自由切换装备 |
| **累计数据** | 模拟次数、战斗次数、存活年数 | 跨周目累加，用于解锁累计类成就 |
| **词条图鉴** | 已见过的词条记录 | 新周目可在图鉴中查看，但词条本身不保留 |
| **NPC图鉴** | 已发现NPC的情报 | 部分情报跨周目保留（见下方） |
| **记忆碎片** | "世界真相"类碎片 | 仅此类型跨周目保留 |

### 1.2 每周目重置内容

| 类别 | 重置内容 | 说明 |
|------|---------|------|
| **境界修为** | 回归炼气1层 | 每世轮回从头修炼 |
| **灵石资源** | 清零（保留成就奖励） | 重新积累 |
| **功法** | 全部遗忘 | 需重新学习 |
| **词条装备** | 全部卸下 | 需重新获取 |
| **NPC关系** | 好感度重置 | 但保留已知情报 |
| **物品背包** | 全部清空 | 从头收集 |

### 1.3 特殊继承：永久词条系统

通过传说级成就解锁的特殊词条，**每个周目可使用1次**：

| 永久词条 | 解锁成就 | 效果 | 使用规则 |
|----------|---------|------|---------|
| 「轮回印记」 | ACH-C08·百世轮回 | 模拟开始时修为+1层 | 每周目首次模拟自动生效 |
| 「弑神之刃」 | ACH-B08·屠龙者 | 战斗中攻击+30%持续1回合 | 每场模拟限触发1次 |
| 「觉醒者」 | ACH-X04·打破第四面墙 | 模拟中隐藏选项显示概率+50% | 每周目持续生效 |
| 「万象归一」 | ACH-L08·全词条解锁 | 模拟开始时随机获得3个蓝色词条 | 每周目首次模拟自动生效 |

**设计原则**：永久词条提供新周目"起步优势"，但不会破坏核心挑战感。每个词条仅提供微量优势，真正的乐趣在于探索不同的命运路径。

## 二、周目差异

### 2.1 一周目（默认体验）

| 特征 | 说明 |
|------|------|
| 难度 | 标准 |
| 可用选项 | 全部基础选项 |
| 可探索区域 | 青云宗、青云城、乱风峡谷 |
| 可用NPC | 6位Demo版NPC |
| 结局类型 | 死亡结局、寿终正寝 |
| 模拟深度 | 炼气期（1-9层） |

### 2.2 二周目（解锁困难模式）

**解锁条件**：完成一次完整模拟（死亡或寿终正寝均可）

| 新增内容 | 说明 |
|----------|------|
| **困难模式选项** | 模拟开始时可开启"困难模式" |
| 困难模式特性 | 突破概率-20%、敌人属性+30%、奇遇奖励品质+1级 |
| **新区域解锁** | 黑风山脉（邪修区域）可探索 |
| **隐藏NPC出现** | "神秘商人"随机出现在坊市（每3年一次） |
| **新事件类型** | "前世记忆闪回"事件（一周目经历的剧情片段） |
| 词条池变化 | 随机天赋池中增加2个专属词条 |

**困难模式奖励加成**：
- 模拟结算奖励品质保底提升1级（白→绿、绿→蓝...）
- 困难模式专属成就可解锁
- 记忆碎片获取率+10%

### 2.3 三周目（解锁真·结局路线）

**解锁条件**：二周目通关 + 收集至少50%的记忆碎片 + 至少1个NPC好感达到"生死"

| 新增内容 | 说明 |
|----------|------|
| **真·结局路线** | 出现"觉醒之路"选项，可探索模拟器真相 |
| **隐藏区域** | "命运之门"（需集齐5枚世界真相碎片开启） |
| **最终BOSS** | "命运守望者"（模拟器意志化身） |
| **新NPC** | "命运守望者"（亦敌亦友，知晓一切真相） |
| 词条池变化 | 随机天赋池中增加5个稀有词条 |
| 灵气复苏加速 | 环境灵气浓度+20%，修炼速度提升 |

**真·结局条件**：
1. 收集全部5枚"世界真相"记忆碎片
2. 与"命运守望者"对话并做出选择
3. 至少3位NPC好感达到"生死"
4. 修为达到炼气9层

**三种结局**：

| 结局 | 条件 | 描述 |
|------|------|------|
| **超脱结局** | 击败命运守望者 | 打破模拟器束缚，获得真正的自由。解锁称号「天命之外」 |
| **融合结局** | 说服命运守望者（需全部NPC生死好感） | 与模拟器合二为一，成为新的命运编织者。解锁称号「命运之主」 |
| **轮回结局** | 放弃抵抗，选择遗忘 | 一切回到起点，但保留所有记忆碎片。解锁称号「永恒旅人」 |

## 三、每周目随机天赋池差异

### 3.1 天赋池机制

每次新周目开始时，系统从"总词条池"中随机选取一个"周目天赋池子集"，影响该周目模拟中词条出现概率。

| 周目 | 池子大小 | 特殊规则 |
|------|---------|---------|
| 一周目 | 默认30个词条 | 标准概率分布 |
| 二周目 | 30+2个专属词条 | 新增词条：「前世残忆」「困难体质」 |
| 三周目 | 30+5个稀有词条 | 新增词条：「命运之眼」「觉醒意志」「真相碎片携带者」「轮回之力」「天命逆转」 |

### 3.2 周目专属词条

| 词条ID | 名称 | 品质 | 效果 | 所属周目 |
|--------|------|------|------|---------|
| TRT-P01 | 前世残忆 | 蓝 | 模拟开始时随机获得1条记忆碎片 | 二周目 |
| TRT-P02 | 困难体质 | 紫 | 全属性+3，但突破概率-10% | 二周目 |
| TRT-P03 | 命运之眼 | 金 | 感知所有隐藏事件，奇遇概率+30% | 三周目 |
| TRT-P04 | 觉醒意志 | 紫 | 心魔免疫，渡劫成功率+20% | 三周目 |
| TRT-P05 | 真相碎片携带者 | 蓝 | 模拟中额外获得1枚世界真相碎片 | 三周目 |
| TRT-P06 | 轮回之力 | 紫 | 修炼速度+30%，寿命+10年 | 三周目 |
| TRT-P07 | 天命逆转 | 金 | 死亡时100%触发"命运逆转"（复活并恢复50%气血，每周目仅1次） | 三周目 |

## 四、隐藏内容

### 4.1 特殊开局

满足特定成就后，新周目可解锁特殊开局选项：

| 开局名称 | 解锁条件 | 初始加成 |
|----------|---------|---------|
| **默认开局** | 无 | 四灵根、炼气1层、10灵石 |
| **世家开局** | 解锁成就ACH-S02（挚友满座） | 初始灵石+50、魅力+3、获得「世家子弟」背景词条 |
| **天才开局** | 解锁成就ACH-C07（百日筑基） | 灵根提升为三灵根、悟性+5 |
| **老兵开局** | 解锁成就ACH-B05（百战神兵） | 攻击力+10%、获得「身经百战」临时词条 |
| **富商开局** | 解锁成就ACH-L05（身家不菲） | 初始灵石+200、魅力+2 |
| **觉醒者开局** | 解锁成就ACH-X04（打破第四面墙） | 神识+5、获得1枚随机记忆碎片 |

### 4.2 隐藏NPC

| NPC名称 | 身份 | 出现条件 | 独特功能 |
|----------|------|---------|---------|
| **神秘商人** | 游走于各大宗门的散修商人 | 二周目起，每3年在坊市出现一次 | 出售稀有物品（玄阶功法、罕见丹药）、收购特殊材料 |
| **命运守望者** | 模拟器的意志化身 | 三周目，集齐5枚世界真相碎片 | 提供终局选择、揭示世界真相 |
| **前世之影** | 玩家在之前周目的数据残影 | 三周目，完成10次以上模拟 | 提供前世记忆线索、可短暂获得前世属性加成 |
| **时间旅人** | 来自未来的修士 | 满足"百世轮回"+"真相碎片"双重条件 | 提供跨周目信息、解锁特殊对话选项 |

### 4.3 隐藏事件

| 事件名称 | 触发条件 | 奖励 |
|----------|---------|------|
| **前世回溯** | 三周目，模拟中出现与一周目相同的事件序列 | 额外记忆碎片×1 |
| **命运分歧点** | 三周目，在同一事件做出与上周目不同选择 | 触发全新剧情分支 |
| **模拟器低语** | 累计模拟50次后，随机在模拟开始/结束时出现神秘文字 | 世界观线索碎片 |
| **时间裂缝** | 三周目，同时装备3个以上永久词条 | 进入"时间裂缝"特殊空间，可重新选择1个历史决策 |

## 七、数据持久化设计

### 7.1 跨周目数据存储结构

```javascript
const metaProgress = {
  // 永久数据（不随周目重置）
  achievements: {},          // 成就解锁状态
  titles: [],                // 已获称号列表
  totalSimulations: 0,       // 累计模拟次数
  totalDeaths: 0,            // 累计死亡次数
  deathMethods: new Set(),   // 经历过的死法种类
  discoveredLocations: new Set(),  // 已发现地点
  worldTruthFragments: [],   // 世界真相碎片
  permanentTerms: [],        // 永久解锁词条
  completedRuns: 0,          // 完成周目数
  npcMetaKnowledge: {},      // NPC跨周目情报
  
  // 当前周目数据（每次新周目重置）
  currentRun: {
    runNumber: 1,
    difficulty: 'normal',
    realmLevel: 1,
    spiritStones: 10,
    // ... 其他玩家数据
  }
};
```

### 7.2 新周目初始化流程

```
1. 保存当前周目统计数据到 metaProgress
2. 重置 currentRun 数据
3. 检查并应用永久词条
4. 根据周目数解锁新内容和区域
5. 生成新的随机天赋池
6. 检查特殊开局解锁条件
7. 进入新周目开局选择界面
```
