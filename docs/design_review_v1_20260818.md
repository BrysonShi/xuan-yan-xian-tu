## 一、数值策划 — 核心数值体系设计

### 1.1 六维属性系统

| 属性 | 英文Key | 默认值 | 核心作用 | 影响场景类型 |
|------|---------|--------|---------|-------------|
| 悟性 | comprehension | 10 | 理解功法、突破瓶颈、领悟阵法 | 修炼突破、功法参悟、阵法破解 |
| 气运 | luck | 10 | 奇遇触发率、闪避致命伤害、随机事件倾向 | 探索奇遇、随机事件、危机闪避 |
| 魅力 | charisma | 10 | NPC好感度、交易议价、说服成功率 | NPC交互、交易谈判、招募队友 |
| 根骨 | strength | 10 | 战斗伤害、体质、承受伤害上限 | 战斗切磋、承受压力、体力活动 |
| 敏捷 | agility | 10 | 闪避率、出手速度、逃跑成功率 | 战斗闪避、逃跑脱身、反应速度 |
| 神识 | spirit | 10 | 感知危险、推演质量、精神抗性 | 危险预知、模拟器推演、精神对抗 |

### 1.2 属性对剧情的影响机制（三层设计）

**第一层：属性加成效果（被动生效）**
- 灵根创建时一次性分配属性加成（已有）
- 词条装备提供属性加成（已有框架）
- 场景 onEnter 根据属性给予额外奖励

**第二层：属性门槛判定（选项解锁/结果分歧）**
- 选项标注 `minAttr: { key: value }`
- 玩家属性达标 → 显示选项 + 额外收益文本
- 玩家属性不达标 → 选项灰色显示 + 提示"需要XX属性≥N"
- 不阻止玩家选择，但结果不同

**第三层：属性影响模拟推演质量**
- 悟性高 → 模拟中获得功法领悟概率↑
- 气运高 → 模拟中遇到奇遇概率↑
- 神识高 → 模拟中获得记忆碎片质量↑
- 根骨高 → 模拟中存活年限↑
- 敏捷高 → 模拟中逃脱死亡率↑
- 魅力高 → 模拟中NPC援助概率↑

## 三、剧情/文案策划 — 剧情逻辑与分支设计

### 3.1 剧情主线结构

```
[序章·觉醒灵根] → [第一章·入门] → [第二章·模拟器觉醒]
       ↓                  ↓                ↓
   灵根决定          外门杂役生活      发现命运模拟器
   初始属性          结识陈墨          第一次推演
   叙事差异          遇见赵无涯        获得记忆碎片

[第三章·历练] → [第四章·暗流] → [第五章·大比]
      ↓              ↓              ↓
  乱风峡谷       苏长老拉拢      内门试炼
  结识马良       李玄真真相      金元果
  遭遇劫修       灰袍老者       封印松动
  神秘老者       上古战场
```

### 3.2 关键分支逻辑审计

#### 后山线（mountain_1 → 2a/2b → 3a/3b/3c）

```
mountain_1（+100修为）
├── A: 深入探查 → mountain_2a（洞府）
│   ├── A: 修炼功法 → mountain_3a（+400修为，大突破）⭐最佳收益
│   └── B: 拿走灵石 → mountain_3b（+200修为+20灵石）稳妥路线
└── B: 谨慎观察 → mountain_2b（灵狐事件）
    ├── A: 救治灵狐 → mountain_3c（+300修为+银灵狐伙伴）❤情感路线
    └── B: 离开 → end_calm（+100修为，平静收场）
```

**逻辑问题**：
- ✅ 分支设计合理，三条路线各有特色
- ️ mountain_3a 收益过高（+400），是 mountain_3c 的 1.3 倍
- 建议：mountain_3a 降至 +350，mountain_3c 升至 +350（平衡战斗/情感路线）

#### 修炼线（training_1 → 2a/2b → 3a/3b/3c）

```
training_1（+100修为，王浩切磋）
├── A: 接受切磋 → training_2a
│   ├── A: 全力迎战 → training_3a（+300修为+5声望）️力量路线
│   └── B: 巧技取胜 → training_3b（+250修为+8声望）技巧路线
└── B: 婉拒修炼 → training_2b（+150修为，瓶颈）
    ├── A: 冲击瓶颈 → training_3c（+350修为，突破）💪爆发路线
    └── B: 稳扎稳打 → end_steady（+200修为，根基）🧘稳健路线
```

**逻辑问题**：
- ✅ 四条路线分别对应不同属性倾向
- ️ 建议加入属性判定：
  - training_3a 需要 根骨≥12，否则收益减半
  - training_3b 需要 敏捷≥12 或 悟性≥12
  - training_3c 需要 神识≥12（感知瓶颈所在）

#### 第一章剧情线（ch1_1 ~ ch1_5）

```
ch1_1（灵根测试，+200修为）→ 线性
ch1_2（丙字院，陈墨，+200修为+5灵石）→ 线性
ch1_3（赵无涯训话，+200修为）→ 线性
ch1_4（王虎霸凌，+200修为）→ 线性
ch1_5（外门大比消息，+300修为）→ 模拟器觉醒
```

**逻辑问题**：
- ❌ **第一章全是线性，无实质分支** → 两个选项都指向同一个 next
- 建议：ch1_4 王虎事件中
  - A: 忍让 → 获得【隐忍】词条，声望-2
  - B: 暗中观察 → 获得【洞察】词条，悟性+2
- 建议：ch1_3 赵无涯训话
  - A: 拼命修炼 → 根骨+2，魅力-1
  - B: 赚灵石 → 灵石+10，修为+100（而非+200）

### 4.3 模拟器沉浸感增强方案

**当前问题**：模拟器只是文字带过"你经历了另一种人生"，玩家没有"在模拟器中经历了，现实掌握情报"的爽感。

**改进方案**：

1. **推演过程可视化**
   - 模拟中每遇到关键事件，显示六维属性判定结果
   - 例如：`[悟性判定 15≥12 ✅] 你理解了功法精髓，修为+200`
   - 失败时：`[根骨判定 10<14 ❌] 你的身体承受不住灵力冲击，受伤`

2. **记忆碎片质量与属性挂钩**
   - 悟性高 → 碎片描述更详细（包含具体功法口诀）
   - 神识高 → 碎片包含隐藏信息（如NPC弱点）
   - 气运高 → 碎片包含奇遇坐标

3. **推演结束时的"情报总结"**
   - 不只是"修为灌注/记忆碎片/词条铭刻"三选一
   - 而是展示本次推演获得的所有情报：
     ```
     📋 推演情报总结：
     · 王浩的收招破绽在右肋（根骨≥12可 exploited）
     · 后山洞府藏有完整功法（悟性≥14可完全理解）
     · 柳飞大比时会使用暗器（神识≥12可提前感知）
     · 你在此次推演中存活了23年
     ```
